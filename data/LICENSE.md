# Licensing of the files in `/data`

TÖLVA's **source code** (HTML, CSS, JavaScript, scripts and tests) is MIT licensed; see [`../LICENSE`](../LICENSE).

The files in **`/data` are not covered by the MIT license.** They are generated by the scripts in `/scripts` from third-party datasets and keep those datasets' licenses. Each generated file's sources, retrieval date, version and checksum are listed in `data/SOURCES.json`.

## What this means for the generated files

- Any file that contains BÍN- or Wiktionary-derived data is distributed under **CC BY-SA 4.0**. Anyone may copy and adapt it, including commercially, if they give the attribution above and share their adaptations under the same license.
- Where a file combines share-alike data with CC BY data (Tatoeba, CLARIN, Talrómur), the file as a whole is offered under CC BY-SA 4.0, and the attribution for every included source is kept.
- Changes made to the source data are described in `data/SOURCES.json`, as CC BY-SA 4.0 section 3(a)(1)(B) requires. DMII Core paradigms are not changed; only their JSON layout is made more compact.

This summary is a good-faith reading of the licenses, not legal advice. The license texts are at https://creativecommons.org/licenses/.
